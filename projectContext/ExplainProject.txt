PROJECT OVERVIEW

We are building a modern web-based Garage Management System (GMS/DMS) for automotive repair workshops and garages.

The platform must centralize and automate all business operations of the garage:

* workshop operations
* repair management
* invoicing
* inventory and spare parts
* customer management (CRM)
* finance and cash register
* reporting and analytics

The system should support:

* multiple user roles
* real-time workshop tracking
* stock management
* digital vehicle inspection
* document generation
* notifications and reminders
* future scalability for multi-garage architecture

IMPORTANT BUSINESS WORKFLOW

Main business flow:

Customer -> Vehicle Reception -> Vehicle Inspection -> Repair Order 
-> Parts Consumption -> Repair Progress -> Invoice -> Payment -> Delivery -> History & Analytics
---------------------
ADDITIONAL BUSINESS WORKFLOWS & USE CASES
* QUICK SERVICE WORKFLOW (oil change, battery replacement, tire service)
    -> Quick diagnosis -> Immediate quotation -> Minor repair/service
    -> Direct payment -> Invoice generation -> Vehicle delivery

* DIGITAL VEHICLE INSPECTION WORKFLOW
    -> Mechanic performs inspection using tablet/mobile -> Checklist validation
    -> Photos/videos attached -> Detected issues recorded -> Diagnostic report generated
    -> Quotation sent to customer -> Customer approval/refusal recorded
        -> Approved repairs converted into active repair tasks
        -> Rejected items archived in repair history

* PHOTO & MEDIA MANAGEMENT WORKFLOW
    Mechanic uploads:  before repair photos
                       during repair photos
                       damaged parts photos
                       videos
    -> Media linked to OR
    -> Media compressed and archived
    -> Accessible from customer/vehicle history


* ADDITIONAL REPAIR DISCOVERY WORKFLOW
    Vehicle already under repair
    -> Mechanic discovers additional issue
        -> Additional diagnosis recorded
        -> Additional quotation generated
        -> Customer approval requested
        -> Workshop status paused until approval
    -> Repair resumes after validation
    -> Delay reason recorded: waiting parts, customer approval, technical issue
    -> Dashboard alerts generated
    -> Daily immobilization KPI updated

* COMEBACK / REPAIR FAILURE WORKFLOW
    Customer returns after recent repair
        -> System links comeback to previous OR
        -> Root cause analysis recorded
        -> Internal quality issue flagged
        -> Warranty/comeback statistics updated


* PART RESERVATION WORKFLOW
    Repair Order scheduled
    -> Required parts reserved automatically
    -> Reserved stock unavailable for other ORs
    -> Reservation released if repair cancelled
    -> Reservation alerts shown to inventory manager


* PARTS / INVENTORY WORKFLOW
    -> Repair Order created -> Required parts identified -> System checks stock availability
        -> If stock available: reserve/deduct stock

        -> If stock unavailable: generate purchase request --> Supplier order created -> Parts received
        -> Inventory updated automatically
     -> Repair continues

* PART RETURNS WORKFLOW
    Unused part identified
    -> Return to inventory
    -> Supplier return possible
    -> Inventory value adjusted
    -> Return history logged

* LOW STOCK ALERT WORKFLOW
    Inventory level reaches threshold
    -> Automatic low stock alert generated
    -> Suggested supplier displayed
    -> Suggested reorder quantity calculated
    -> Purchase request generated


*PURCHASE & SUPPLIER WORKFLOW
    Receptionist creates supplier quotation request
    -> Multiple supplier responses -> Price comparison -> Supplier selection
    -> Purchase Order generation -> Partial/full reception of parts -> Stock updated -> Supplier invoice archived


* CUSTOMER DEBT / CREDIT WORKFLOW
    -> Customer makes partial payment -> Remaining balance tracked -> System updates customer outstanding amount
    -> If threshold exceeded: customer flagged
        -> Automatic reminders sent
    -> Payment settlement recorded

* CASH REGISTER WORKFLOW
    -> Invoice generated -> Payment received -> Payment method selected: cash/card/transfer/cheque
    -> Receipt generated -> Daily cash closing -> Sales journal generated
    -> Accounting export

* VEHICLE HISTORY WORKFLOW
    -> Customer vehicle returns -> System retrieves complete history: (previous repairs invoices mileage inspections)
    -> Mechanic reviews historical problems -> Faster diagnosis and service
    
* CUSTOMER NOTIFICATION 
    vehicle ready
    unpaid invoice
    maintenance reminder
    technical inspection due
    -> SMS/email notification generated
    -> Notification logged in system

* WORKSHOP PERFORMANCE WORKFLOW
    Mechanic starts repair task
        -> Time tracking starts
        -> Repair progress updated
        -> Task completed
        -> System calculates: repair duration mechanic productivity workshop occupancy
        
        -> KPI dashboards updated

WORKFLOWS FOR COMMERCIAL, FINANCE, PURCHASE, AND CRM MODULES

* STANDARD REPAIR INVOICING WORKFLOW
    Customer vehicle enters garage
        -> Reception creates Repair Order
        -> Mechanic diagnoses vehicle
        -> Required labor and parts are added to OR
        -> System calculates estimated cost
        -> Quotation is generated
        -> Customer approves quotation
        -> Repair is completed
        -> Quotation is converted into invoice
        -> VAT, discounts, margins, and totals are calculated
        -> Payment is recorded
        -> Invoice is marked as paid or partially paid
        -> Customer account balance is updated
        -> Vehicle is delivered

* QUOTATION TO INVOICE WORKFLOW
    Reception creates quotation
        -> Labor lines and parts lines are added
        -> System checks parts availability and prices
        -> Discount may be applied
        -> Quotation PDF is generated
        -> Quotation is sent to customer by email/SMS
        -> Customer status becomes: Pending Approval
        -> Customer approves
        -> Quotation is converted into Repair Order or Invoice
        -> Original quotation remains archived for traceability

    Statuses: Draft -> Sent -> Approved -> Converted -> Archived
              Draft -> Sent -> Rejected -> Archived


* CUSTOMER CREDIT LIMIT WORKFLOW
    Reception creates invoice or quotation
        -> System checks customer outstanding balance
        -> If balance is below threshold, operation continues
        -> If balance exceeds threshold, system blocks new credit sale
        -> Reception can request admin validation
        -> Admin approves or rejects exception
        -> If approved, invoice/OR continues
        -> If rejected, customer must pay before service continues

    <>Only Admin can modify credit limit threshold.<>

* PARTIAL PAYMENT WORKFLOW
    Invoice generated
        -> Customer pays part of total amount
        -> Payment method selected: cash, cheque, bank transfer, TPE
        -> System records paid amount
        -> Remaining balance is calculated
        -> Invoice status becomes Partially Paid
        -> Customer account balance is updated
        -> Reminder date can be created automatically
        -> Final payment closes invoice

    Statuses: Unpaid -> Partially Paid -> Paid
              Unpaid -> Overdue
              Partially Paid -> Overdue

* ADVANCE PAYMENT / DEPOSIT WORKFLOW
    Customer accepts quotation
        -> Garage requests advance payment
        -> Reception records deposit
        -> Deposit receipt is generated
        -> Deposit is linked to customer and Repair Order
        -> Final invoice deducts deposit automatically
        -> Remaining amount is paid at delivery


* CASH REGISTER CLOSING WORKFLOW 
    During the day, payments are recorded   
        -> Each payment is linked to invoice/customer/payment method
        -> At end of day, cashier launches cash closing.
    -> System summarizes: cash total - TPE total - cheque total - bank transfer total - refunds - cancellations
    -> Cashier validates counted physical cash
    -> Difference is recorded if any
    -> Daily cash closing report is generated
    -> Sales journal is archived
    -> Accounting export becomes available


* INVOICE CANCELLATION / CREDIT NOTE WORKFLOW
    Invoice created incorrectly
        -> User requests cancellation
        -> System checks if invoice is already paid/exported
        -> If not exported, admin may cancel invoice
        -> If already paid/exported, system creates credit note
        -> Stock and customer balance are adjusted if needed
        -> Audit log records who performed the action and why

* CUSTOMER REFUND WORKFLOW
    Customer overpaid or invoice cancelled
        -> Refund request created
        -> Admin validates refund
        -> Refund method selected
        -> Customer balance adjusted
        -> Cash register records outgoing payment
        -> Audit log updated



* SUPPLIER PURCHASE REQUEST WORKFLOW 
    Stock reaches minimum threshold
        -> System creates low-stock alert
        -> Reception creates purchase request
        -> Required parts and quantities are added
        -> Supplier quotations may be requested
        -> Purchase request waits for approval
        -> Admin/manager validates
        -> Purchase order is generated

* SUPPLIER PRICE COMPARISON WORKFLOW
    Reception needs a part  
        -> System lists available suppliers
        -> Supplier prices, delivery times, and history are displayed
        -> Reception compares: price, delivery delay, previous reliability, equivalent parts
        -> Best supplier is selected
        -> Purchase order is created
        -> Price history is updated

* PURCHASE ORDER RECEPTION WORKFLOW
    Purchase order sent to supplier
        -> Supplier delivers parts
        -> Reception receives delivery
        -> Delivery can be: complete, partial, rejected
        -> Received quantities update stock
        -> Missing quantities remain pending
        -> Supplier delivery note is archived
        -> Supplier invoice can be attached
        -> Stock valuation is updated

    Statuses:
        Draft -> Sent -> Partially Received -> Completed
        Draft -> Sent -> Cancelled


* SUPPLIER INVOICE WORKFLOW
    Supplier invoice received
        -> Invoice is linked to purchase order
        -> System compares: ordered quantities
                            received quantities
                            invoiced quantities
                            agreed prices
        -> If differences exist, invoice is flagged
        -> If valid, supplier invoice is approved
        -> Payable amount is recorded
        -> Accounting export prepared


* CUSTOMER ACCOUNT FOLLOW-UP WORKFLOW
    Customer has unpaid invoices
        -> System tracks due dates
        -> Reminder level increases over time
        -> First reminder sent automatically
        -> Second reminder sent after delay
        -> Customer may be blocked if debt exceeds threshold
        -> Payment settlement clears reminder status
        -> Full reminder history is kept

    Reminder levels: Friendly Reminder -> Formal Reminder -> Blocked Account


* CUSTOMER SEGMENTATION WORKFLOW
    System analyzes customer behavior:
        total revenue
        number of visits
        unpaid invoices
        vehicle type
        last visit date
        satisfaction rating

    -> Customer segment is assigned: VIP, Regular, New, At-risk, Debtor
    -> Segment can be used for reporting


* CUSTOMER FIDELITY / LOYALTY WORKFLOW
    Customer pays invoice
        -> System calculates loyalty points
        -> Points depend on invoice amount/service type
        -> Customer loyalty score updated
        -> Discounts or benefits may be proposed
        -> Loyalty history remains visible on customer profile
    
* MARGIN CALCULATION WORKFLOW
    Invoice or quotation contains parts and labor
        -> System retrieves: part purchase price, part selling price, labor rate, discounts
        -> Margin calculated by line and document
        -> Low-margin alert shown if margin below threshold
        -> Admin dashboard updates profitability KPIs


* CLIENT COMPANY / FLEET BILLING WORKFLOW
    Company customer owns multiple vehicles
        -> Repairs are performed on different vehicles
        -> Invoices can be grouped by company account
        -> Monthly statement generated
        -> Partial or full payment recorded
        -> Outstanding balance tracked at company level
        -> Fleet profitability report generated

* ACCOUNTING EXPORT WORKFLOW
    Invoices, payments, credit notes, and supplier invoices are validated
        -> Accountant selects export period
        -> System generates export file
            -> Export format selected: CSV, Excel, accounting software format
        -> Export includes:
            sales journal
            payment journal
            supplier purchases
            VAT summary
        -> Export file is downloaded
        -> Export archived
        -> Export status tracked : Exported records are locked or marked as exported


* DOCUMENT GENERATION WORKFLOW
    User creates business document: OR, quotation, invoice, delivery note, credit note
        -> System applies document template
        -> Document number generated automatically
        -> VAT, totals, and legal mentions added
        -> PDF generated
        -> Document archived in customer and vehicle profile
        -> Document can be printed or sent by email


* DOCUMENT MANAGEMENT WORKFLOW
    Vehicle/customer documents uploaded: registration card insurance CIN/passport accident photos invoices
        -> Documents categorized
        -> Archived securely
        -> Searchable from customer/vehicle profile


* ADMIN & SECURITY WORKFLOW
    Admin creates user account
        -> Assign role and permissions
        -> User activity logged
        -> Sensitive actions audited
        -> Automatic backups executed
        -> Security alerts generated if abnormal activity detected

* AUDIT & TRACEABILITY WORKFLOW
    Critical action occurs: 
        - invoice modification
        - stock adjustment
        - deleted repair order
        - payment cancellation
    -> Audit log generated: user, timestamp, Old value, new value
    -> Admin can review history


* ANALYTICS & REPORTING WORKFLOW
    System aggregates operational data
        -> Dashboard updates in real time
        -> KPIs calculated : revenue, margins, unpaid invoices, workshop occupancy, stock valuation
        -> Export reports to PDF/Excel
